# AI 工具站 SEO 小册子：图解入门

一本面向 AI 工具站、SaaS 官网和独立开发者的 SEO 实战小册子。

这本书不把 SEO 写成零散技巧，而是把它当成一套长期竞争的系统工程：产品承接搜索需求，内容提供信息增量，技术保证页面可见，外链建立站外信任。
